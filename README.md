## 🛠️ How to save your custom words (V9)
1. Open the **Latest Version**.
2. Go to **Settings**.
3. Add your words and click **Download Updated App**.
4. Come back to this GitHub repository.
5. Click **Add file > Upload files**.
6. Drag your NEW `index.html` here to overwrite the old one.
